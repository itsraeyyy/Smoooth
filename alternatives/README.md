# Alternatives Architecture: /alternatives/

Category-level evaluation pages for developers searching for alternatives to centralized PaaS or legacy DevOps tooling.

## Canonical Rules
- **Base Path:** `https://smoooth.dev/alternatives/<competitor>`
- **Page Type:** Alternatives / Category Guide
- **Search Intent:** Commercial Investigation ("coolify alternative", "vercel self-hosted alternative")
- **Editorial Standard:** Strict fairness. Give accurate pros/cons. Never claim competitors lack features they possess. Include "As of October 2026" attribution.
- **Required Sections:**
  1. What the category is and why developers seek alternatives.
  2. Direct side-by-side criteria (RAM overhead, MCP support, agent sandboxing, cloud lock-in).
  3. When to choose Smoooth vs when to stay with the alternative.
  4. Migration path / zero-downtime adoption steps.
