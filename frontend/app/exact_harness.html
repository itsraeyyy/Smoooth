Stateful Database Adapters

Provision PostgreSQL, Redis, MongoDB, and SQLite with automated volume retention, health verification, and clean rollbacks. Zero cloud markups.

Scoped Security & Least Privilege

Never grant an AI agent an unrestricted root shell. Enforce 256-bit cryptographic bearer tokens with granular role-based permissions (read_only, plan, deploy, admin).

Transactional 2-Phase DAG Deployments

Every deployment validates an execution plan before provisioning. If a container fails health checks, Smoooth rolls back automatically to the last healthy state.

Execution Audit Stream

Inspect topological DAG steps, container log streams, and environment health probes directly from your agent conversation or terminal.

From VPS to Agent-Operated

1. Install Daemon

Run the idempotent installer on Ubuntu 24.04 or Debian 12. Sets up sandboxed systemd daemon and Docker bridge.

$ curl -fsSL https://smoooth.dev/install.sh | bash

2. Pair Coding Agent

Pair Claude Code, Cursor, or Windsurf directly over local loopback using your 256-bit scoped bearer token.

$ git clone https://github.com/itsraeyyy/Smoooth
