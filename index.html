From Bare VPS to Agent-Operated
in Under 2 Minutes

Install once on Ubuntu 24.04 or Debian 12. Connect any MCP-compatible coding tool over local loopback.

01 SYSTEMD DAEMON

Install the Daemon

The idempotent installer configures an unprivileged service account, systemd isolation, and a 256-bit bearer token. 

sudo ./install.sh --show-token
02 MCP PROTOCOL

Pair Your Coding Agent

Point Claude Code, Cursor, or Windsurf to Smoooth's loopback endpoint. Zero unauthenticated port exposure. 

claude mcp add --transport sse smoooth \
  http://127.0.0.1:4040/sse \
  --header "Authorization: Bearer <TOKEN>"
03 AUTONOMOUS RUNTIME

Prompt to Provision & Deploy

Smoooth resolves dependencies into a topological DAG, creates persistent volumes, and verifies container health probes. 

"Deploy my web app with PostgreSQL 
and Redis, and expose it on port 8000."

Security, Control, and
Zero Cloud Lock-In

Smoooth was designed specifically to prevent runaway agents and avoid surprise cloud bills.

Zero Cloud Lock-In

Runs on any $5 VPS, bare-metal server, or home lab. Your data stays on your own SSDs without proprietary PaaS pricing tiers.

Private by Default

The daemon binds exclusively to 127.0.0.1:4040. Access the embedded web dashboard securely via SSH tunnel with zero public attack surface.

Transactional 2-Phase DAG

Every deployment validates an execution plan before provisioning. If a container fails health checks, Smoooth rolls back automatically.

Local-First Observability

Embedded dashboard with strict Content Security Policy (CSP), offline platform typography, and append-only audit logging. Zero external telemetry.
